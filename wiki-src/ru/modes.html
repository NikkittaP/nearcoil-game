{{ t('RANKED') }}

Бесконечный режим. Одни правила для всех: стандартное поле и скорость, все четыре события и все три модуля. Забег длится до столкновения.

  • Лучший счёт попадает в онлайн-рейтинг: мир, твоя страна (выбирается в настройках, менять можно раз в 30 дней) или платформа, за всё время или за неделю.
  • Нажми на имя в таблице: {{ t('PF_TITLE') }} откроет профиль игрока, {{ t('WATCH') }} — повтор его забега (он есть у каждого забега в таблице). Сервер переигрывает присланные забеги, чтобы их проверить.
  • Без сети забег засчитывается локально и отправляется позже.

Недельные лиги

Когда игроков становится достаточно ({{ league.min_players }} за неделю), недельная таблица делится на лиги — как в Duolingo:

  • Первый забег на рекорд за неделю ставит тебя в группу примерно из {{ league.group_size }} игроков твоей ступени. Очки в лиге — твой лучший забег за неделю.
  • Неделя кончается в понедельник в 00:00 UTC: первые {{ league.promote }} каждой группы поднимаются на ступень, последние {{ league.demote }} — опускаются.
  • {{ league.tiers }} ступеней, снизу вверх: {{ t('LEAGUE_T0') }}, {{ t('LEAGUE_T1') }}, {{ t('LEAGUE_T2') }}, {{ t('LEAGUE_T3') }}, {{ t('LEAGUE_T4') }}, {{ t('LEAGUE_T5') }}. Награды только косметические.

Пока игроков меньше, показывается обычная недельная таблица.

{{ t('DAILY') }}

  • Одно поле в день, одинаковое для всех: те же узлы при тех же ходах и те же события. Новое начинается каждый день в 00:00 UTC.
  • {{ Economy.DAILY_RANKED_ATTEMPTS }} зачётные попытки в день. Попытка тратится в момент старта, так что выход после неудачного начала её всё равно расходует. Потом можно тренироваться на поле дня до завтра.
  • В рейтинг дня идёт лучшая зачётная попытка.
  • Первая попытка дня возвращает один предохранитель кампании.
  • Недельная цель: пройди испытание дня в {{ Economy.WEEKLY_DAILY_GOAL }} разных дней одной недели (с понедельника по воскресенье, UTC) — и получишь +{{ Economy.WEEKLY_DAILY_FUSES }} предохранитель, раз в неделю. Он начисляется даже при полном запасе (до {{ Economy.FUSE_MAX + Economy.FUSE_BONUS }}/{{ Economy.FUSE_MAX }}). Вторая попытка в тот же день и тренировка не считаются. История испытаний за месяц — на вкладке {{ t('ACH_CAT_DAILY') }} в разделе {{ t('ACHIEVEMENTS') }}.
  • Для зачётных попыток нужна сеть (их выдаёт сервер); без сети — только тренировка.
  • Испытание дня идёт ровно по правилам игры на рекорд.

{{ t('CAMPAIGN') }}

{{ img('campaign_map', 'Карта кампании: глава 2, ВОРОТА, медали на пройденных уровнях.') }}

{{ derived.levels_total }} уровней в {{ derived.chapters_total }} главах. Каждая глава учит одной идее и заканчивается экзаменом; каждый уровень меняет несколько правил (поле, скорость, события, модули, старт). Полный список со всеми целями — на странице Все уровни кампании.

Цели и медали

  • У каждого уровня три цели по очкам — {{ term('PASS') }}, {{ term('GREAT') }} и {{ term('PERFECT') }} — и лимит времени.
  • Уровень кончается, когда вышло время, при столкновении или сразу, как только набран ИДЕАЛ. Медаль — лучшая цель, до которой дошёл счёт; очки при столкновении не теряются, так что полученная медаль остаётся, даже если потом разобьёшься.
  • Получив медаль, можно завершить уровень из меню паузы.
  • {{ t('PASS') }} открывает следующий уровень. Пройденные уровни можно переигрывать когда угодно ради медали получше.
  • У многих уроков на карточке уровня есть кнопка {{ t('SHOW_DEMO') }}: короткая демонстрация приёма.

{{ t('FUSES') }}

  • Предохранителей не больше {{ Economy.FUSE_MAX }}. Один восстанавливается каждые {{ Economy.FUSE_REGEN_S // 60 }} минут (полный запас за {{ Economy.FUSE_MAX * Economy.FUSE_REGEN_S // 60 }} минут).
  • Предохранитель сгорает, только когда ты проваливаешь ещё не пройденный уровень (без медали) — в том числе выходишь из него посреди забега. Выход с карточки уровня ничего не стоит.
  • Переигровка пройденных уровней бесплатна. Глава 1 предохранители не тратит.
  • Игра на рекорд, испытание дня и тренировка ничего не стоят.
  • {{ t('FULL_RECHARGE') }} (покупка в игре) заполняет запас; первая попытка испытания дня даёт один предохранитель.

Награды за главы

За прохождение главы открывается цвет для бесплатной темы SIGNATURE ({{ t('COBALT') }}, {{ t('VIOLET') }}, {{ t('ACID') }}, {{ t('ROSE') }}, {{ t('ICE') }}, {{ t('GOLD') }}, {{ t('WHITE') }}). Он сразу включается; другой цвет или оригинал можно выбрать в разделе «Темы».

После забега

{{ img('results', 'Экран итогов со статистикой забега.') }}
  • Итоги показывают счёт, рекорд и максимальный множитель, а также цифры забега: длину, сближения, СКВОЗЬ, ЗАЖИМЫ, ИГЛЫ, ворота, реле, провода и модули.
  • {{ t('REPLAY') }} проигрывает забег на 1×, 2× или 4× и умеет перейти к лучшему моменту.
  • Новые достижения появляются карточками поверх итогов, а под ними — ближайшие следующие.
  • {{ t('CREATE_VIDEO') }} собирает вертикальный ролик 60 кадров/с: {{ t('FULL_RUN') }} или {{ t('BEST_MOMENTS') }}, на скорости 1×, 2×, 4× или 8×. В каждом ролике — твой ник, режим и дата. Кнопка языка ({{ t('VIDEO_LANG') % t('LANG_ru') }}) выбирает язык ролика: можно играть на одном языке, а делиться на другом. Ролики со скоростью и языком твоей записи готовы сразу, остальные собираются на телефоне за несколько секунд. {{ t('SHARE') }} отправляет вместо ролика карточку с результатом.

Честно по замыслу

Ничего из того, что можно купить, не влияет на счёт. Темы — только оформление (они не меняют размеры объектов, тайминги и подсчёт очков), модули и попытки не продаются, а игра на рекорд и испытание дня всегда бесплатны.
