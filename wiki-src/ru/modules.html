Порты ({{ t('CHOOSE') }})

{{ img('ports', 'Два порта модулей после выигранного события: выбирай поворотом.') }}
  • Порты открываются после выигранного события (на уровнях кампании — если там разрешены модули). Один или два порта появляются в {{ Circuit.PORT_REACH[0] }}–{{ Circuit.PORT_REACH[1] }} клетках от головы, по возможности по разные стороны от направления движения — настоящая развилка.
  • На выбор есть {{ steps(Circuit.PORT_TIME) }}. Въехал в порт — забрал его модуль, второй порт исчезает.
  • Что может выпасть: {{ t('PHASE') }}, если её у тебя ещё нет; {{ t('SURGE') }} всегда; {{ t('CUT') }}, только если тело не короче {{ Circuit.CUT_MIN_LEN }} клеток и среза у тебя ещё нет.
  • Одновременно можно держать не больше одной ФАЗЫ и одного СРЕЗА. Модуль, который у тебя есть, показан справа на полосе события.

{{ t('PHASE') }}

{{ img('phase', 'Урок 4-01: с ФАЗОЙ голова перепрыгивает ряд изоляторов.') }}

Пока у тебя есть ФАЗА, следующее столкновение с проводником не заканчивает забег: голова перепрыгивает эту одну клетку и оказывается с другой стороны.

  • Работает с любым проводником: твоим телом, столбами, живыми стойками, шинами, проводами и изоляторами. Прыжок ровно на одну клетку, поэтому клетка за препятствием должна быть свободна.
  • Край поля по-прежнему убивает; убивает и проводник, за которым нет свободной клетки.
  • Прыжок даёт +{{ Circuit.PHASE_PTS }} очков (× множитель) и +{{ Circuit.PHASE_FLOW }} заряда — используй его специально, а не только как запасную жизнь.

{{ t('CUT') }}

{{ img('cut', 'Урок 4-05: следующий узел отрезает самую старую часть тела.') }}

Следующий узел, съеденный после взятия СРЕЗА, отрезает самую старую часть тела.

  • Отрезается {{ pct(Circuit.CUT_PCT) }} тела со стороны хвоста, но в теле всегда остаётся не меньше {{ GameSim.START_LEN }} клеток.
  • Каждая отрезанная клетка разряжается в шкалу: +{{ Circuit.CUT_FLOW_PER_CELL }} заряда за клетку.
  • Освобождает место на тесном поле; цена — меньше тела, вдоль которого можно скользить.
