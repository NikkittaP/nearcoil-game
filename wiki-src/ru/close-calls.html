Сближение ({{ t('GRAZE') }})

{{ img('graze', 'Урок 1-03: голова идёт вдоль собственного тела; каждая новая клетка тела рядом — сближение.') }}

После каждого шага игра смотрит на четыре клетки вокруг головы (сверху, снизу, слева, справа — не по диагонали). Каждая, в которой есть проводник, даёт сближение:

  • Твоё тело, но только его старая часть: {{ GameSim.MIN_AGE }} клеток сразу за головой (шея и крутая шпилька) не считаются, как и самый кончик хвоста, который сейчас уедет. Нужно по-настоящему ехать вдоль тела.
  • Конструкции: изоляторы кампании, столбы ворот, живые стойки и шины реле, провода под током. Врезаться в них смертельно, но для сближений они годятся.

Правила, которые держат игру честной:

  • Каждая клетка тела срабатывает один раз. После этого внутри неё видна тонкая искра («заряжена»), и больше она не платит.
  • Клетка поля, в которой голова только что дала сближение, не может дать новое ещё {{ GameSim.GRAZE_COOLDOWN }} шагов — так нельзя бесконечно кружить за собственным хвостом.
  • Изолятор платит, гаснет и снова загорается через {{ GameSim.WALL_REARM }} шагов (ниже).

Заряд от сближений — «мелкий»: чем выше множитель, тем меньшая его часть до тебя доходит — {{ pct(GameSim.FLOW_MINOR_TAPER[0]) }} на ×1, {{ pct(GameSim.FLOW_MINOR_TAPER[2]) }} на ×3 и всего {{ pct(GameSim.FLOW_MINOR_TAPER[4]) }} на ×5. Одними сближениями множитель поднимается примерно до ×3; выше нужны манёвры. В горячей зоне каждое сближение заряжает полностью.

Тесные шаги и манёвры

Тесный шаг — шаг, на котором обе боковые клетки головы (слева и справа по ходу движения) заняты проводником: ты в щели шириной в одну клетку. Каждый тесный шаг со свежей стороной даёт {{ GameSim.FLOW_TIGHT }} заряда, а пока ты внутри щели, шкала не утекает.

Когда голова выходит из щели, серия тесных шагов оценивается:

То есть щель в один шаг считается СКВОЗЬ, только если она правда ведёт сквозь стену из твоего тела; короткая щель с лёгким обходом — это ЗАЖИМ (от двух шагов) или ничего (один шаг).

Только свежие стороны

Щель платит, только если хотя бы одна её сторона — свежее тело, ещё ни разу не бывшее стороной щели. Повторный проезд по тому же коридору ничего не даёт. Щель только из столбов — тоже не манёвр: за неё платят сами ворота.

Серии

Манёвр, сделанный меньше чем через {{ GameSim.CHAIN_WINDOW }} шагов после предыдущего, продолжает серию (на экране — {{ t('CHAIN %d').replace('%d', 'N') }}). Серия умножает и очки, и заряд манёвра:

{{ table(['Манёвр в серии', '1-й', '2-й', '3-й', '4-й', '5-й и дальше'], [['Бонус', '×1', '×1,25', '×1,5', '×1,75', '×2']], 'num') }}

Серия прерывается, если {{ GameSim.CHAIN_WINDOW }} шагов проходят без манёвра или шкала опустела.

Пример

СКВОЗЬ через щель в одну клетку на ×3, второй манёвр серии: (60 + 4 × 1) × 1,25 = 80 базовых очков, × 3 = {{ (GameSim.PTS_THREAD + GameSim.PTS_TIGHT) * 5 // 4 * 3 }} очков и {{ GameSim.FLOW_THREAD * 5 // 4 }} заряда.

Столкновение внутри щели ничего за неё не даёт: забег кончается, СКВОЗЬ или ЗАЖИМ не засчитан.

Изоляторы

{{ img('insulator', 'Урок 1-06: горящие блоки на поле; тот, мимо которого только что проехали, погас.') }}

На полях кампании бывают неподвижные блоки — изоляторы. Врезаться в них — конец забега. Проход впритирку — сближение, которое всегда оплачивается полностью (это не твоё тело, голод на него не действует). После сближения блок гаснет и загорается снова через {{ GameSim.WALL_REARM }} шагов. Изоляторы тоже бывают стенками щели: ЗАЖИМ между телом и рядом блоков засчитывается.
