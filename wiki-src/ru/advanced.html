Здесь собраны подробности механики для тех, кто хочет выжать максимум из забегов на рекорд. Чтобы получать удовольствие от NEARCOIL и хорошо играть, знать эти числа не нужно — всё важное остальной справочник объясняет простыми словами.

Скорость

Базовая длина шага зависит только от того, сколько узлов съедено:

{{ speed_table() }}

Множитель добавляет от +{{ GameSim.FLOW_SPEED_PCT[1] }}% на ×2 до +{{ GameSim.FLOW_SPEED_PCT[-1] }}% на ×{{ len(GameSim.FLOW_LEVELS) }} (см. таблицу), ФОРСАЖ — ещё +{{ Circuit.SURGE_SPEED_PCT }}%. Шаг никогда не бывает короче {{ GameSim.MIN_INTERVAL }} мс.

шаг = базовый шаг × 100 / (100 + прибавка множителя % + прибавка ФОРСАЖА %), но не меньше {{ GameSim.MIN_INTERVAL }} мс

«Около N с» на этой странице считается для типичного раннего шага в 150 мс.

Рост и расстановка узлов

{{ growth_table() }}

После {{ len(GameSim.GROWTH) }}-го узла каждый следующий добавляет {{ GameSim.GROW_LATE }} {{ plural(GameSim.GROW_LATE, ('', ''), ('клетку', 'клетки', 'клеток')) }}.

  • Узел никогда не появляется ближе 4 клеток (по шагам) к голове.
  • Клетки вплотную к телу и на средней дистанции (до 11 клеток) выпадают чаще.

Смахивание срабатывает, когда палец сдвинулся примерно на {{ int(Main.FLICK_DP) }} dp.

Пороги множителя

Заряд — число от 0 до {{ GameSim.FLOW_MAX }}.

{{ flow_table() }}
  • Заряд от — сколько заряда нужно для этого множителя.
  • Заряд за сближения — какая доля заряда от сближений, скольжения и тесных шагов доходит до тебя на этой ступени (манёвры и события не урезаются; в горячей зоне сближения всегда заряжают полностью).
  • Утечка — сколько заряда теряется за шаг после окончания удержания: меньшее значение — пока голова в пределах 2 клеток от проводника, большее — на просторе.

Удержание и утечка

  • После прироста шкала держится {{ steps(GameSim.FLOW_GRACE) }}. Прирост от сближений покупает удержание, урезанное в той же доле, что и заряд; манёвр или событие — полное.
  • После падения на ступень есть передышка в {{ GameSim.FLOW_DROP_GRACE }} шагов, прежде чем начнёт утекать следующая.
  • Голод: игра у своего тела оплачивается полностью {{ steps(GameSim.HUNGER_GRACE) }} после последнего узла, затем за {{ steps(GameSim.HUNGER_FADE) }} равномерно падает до нуля.

Как распознаются сближения и манёвры

  • {{ GameSim.MIN_AGE }} клеток тела сразу за головой никогда не дают сближения.
  • Клетка поля, где голова только что дала сближение, не может дать новое ещё {{ GameSim.GRAZE_COOLDOWN }} шагов.
  • Сближение не позже чем через {{ GameSim.SKIM_GAP + 1 }} шага после прошлого — это {{ t('SKIM') }}.
  • Изолятор загорается снова через {{ GameSim.WALL_REARM }} шагов после выплаты.
  • Длина щели: {{ t('SQUEEZE') }} — {{ GameSim.SQUEEZE_MIN }}–{{ GameSim.NEEDLE_MIN - 1 }} тесных шагов, {{ t('NEEDLE') }} — от {{ GameSim.NEEDLE_MIN }}, {{ t('THREAD') }} — 1–{{ GameSim.THREAD_MAX }}, если обхода короче {{ GameSim.DETOUR_MIN }} клеток нет.
  • Манёвр продолжает серию, если сделан меньше чем через {{ GameSim.CHAIN_WINDOW }} шагов после предыдущего.

Расписание событий

  • Первое событие начинается после {{ steps(Circuit.FIRST_EVENT) }} свободной игры.
  • Между событиями — {{ Circuit.GAP_MIN }}–{{ Circuit.GAP_MAX }} шагов, на {{ Circuit.GAP_SHRINK }} меньше за каждое пройденное событие, но не меньше {{ Circuit.GAP_FLOOR }}. Если событие закончилось на ×5 и выше, добавляется {{ Circuit.RECOVERY_HOT }} спокойных шагов.
  • Новые конструкции появляются не ближе {{ Circuit.SAFE_DIST }} клеток от головы.
  • Виды тянутся из перемешанного мешка без повторов подряд; {{ t('LIVE WIRE') }} добавляется после первых {{ Circuit.WIRE_AFTER }} событий.
  • Интенсивность = число пройденных событий, +1 пока у тебя ×5 и выше. Она открывает сложные варианты ниже; вес — доля варианта при выборе.
