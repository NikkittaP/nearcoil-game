Их четыре вида: {{ t('GATE') }}, {{ t('RELAY') }}, {{ t('HOT ZONE') }} и {{ t('LIVE WIRE') }}, и у каждого есть варианты. Выигранное событие приносит очки и заряд и открывает выбор модуля. ---

Когда приходят события

  • Первое событие начинается после {{ steps(Circuit.FIRST_EVENT) }} свободной игры.
  • Между событиями — {{ Circuit.GAP_MIN }}–{{ Circuit.GAP_MAX }} шагов свободной игры. Пауза сокращается на {{ Circuit.GAP_SHRINK }} шагов с каждым пройденным событием, но не меньше {{ Circuit.GAP_FLOOR }}. Если событие закончилось, когда у тебя было ×5 или больше, добавляется ещё {{ Circuit.RECOVERY_HOT }} спокойных шагов.
  • Событие не начинается, пока ты внутри щели, а новые конструкции появляются не ближе {{ Circuit.SAFE_DIST }} клеток от головы и никогда прямо у тебя на пути. Если поле слишком забито, событие чуть ждёт и пробует снова.
  • Название, прогресс и таймер события — в полосе под шкалой. При первой встрече с каждым видом игра показывает карточку с объяснением.
  • Если время вышло, событие просто кончается без награды. Конструкции исчезают вместе с событием (стойки реле держатся ещё немного).

Какое событие (на рекорд и испытание дня)

Виды тянутся из перемешанного мешка, который не выдаёт один вид дважды подряд. {{ t('LIVE WIRE') }} добавляется только после первых {{ Circuit.WIRE_AFTER }} событий. Сложные варианты открываются с ростом интенсивности забега — это число уже пройденных событий плюс один, пока у тебя ×5 и выше. В таблицах ниже — с какой интенсивности доступен вариант и его вес при выборе. Уровни кампании задают события и варианты явно (см. все уровни).

{{ t('GATE') }}

{{ shots( img('gate', 'Серия ворот: два ряда столбов, между ними дверь; следующие ворота уже ждут.'), img('gate_pass', 'Ворота пройдены: надпись показывает их номер в серии.'), img('gate_double', t('DOUBLE GATE') + ': две двери, подойдёт любая.'), img('gate_risk', t('RISK GATE') + ': мелкая дверь даёт +25, глубокая +90.'), ) }}

Ворота — это дверь (прямой проход длиной 1–4 клетки) и смертельный столб с каждой стороны от каждой клетки двери. Чтобы пройти ворота, въедь в дверь и выедь с другой стороны насквозь, не поворачивая внутри. Направление любое. Длина двери — её глубина; глубокие двери платят больше.

  • Каждые ворота нужно пройти за {{ steps(Circuit.GATE_TIME) }}; для следующих ворот серии таймер начинается заново.
  • Новая дверь появляется в {{ Circuit.GATE_REACH[0] }}–{{ Circuit.GATE_REACH[1] }} клетках от головы. Столб никогда не ставится на твою линию ближе {{ Circuit.GATE_LANE_CLEAR }} клеток впереди и на соседние линии ближе {{ Circuit.GATE_SIDE_CLEAR }} клеток.
  • Столбы — проводники: проход впритирку к ним — сближение (оплачивается полностью), проезд между ними — тесные шаги. Щель из одних столбов манёвром не считается — за неё платят ворота.

Варианты

{{ director_table('gate') }}
  • {{ t('RISK GATE') }}: мелкая дверь (глубина {{ Circuit.RISK_SAFE[0] }}) — +{{ Circuit.RISK_SAFE[1] }} очков и {{ Circuit.RISK_SAFE[2] }} заряда; глубокая (глубина {{ Circuit.RISK_DEEP[0] }}) — +{{ Circuit.RISK_DEEP[1] }} очков и {{ Circuit.RISK_DEEP[2] }} заряда. Первая пройденная дверь заканчивает событие.
  • {{ t('ECHO GATE') }}: одна дверь глубиной {{ Circuit.ECHO_DEPTH }}, её надо пройти {{ Circuit.ECHO_PASSES }} раза — туда, обратно и снова туда, каждый раз за {{ Circuit.ECHO_TIME }} шагов. Проходы платят {{ lst(Circuit.ECHO_PTS) }} очков и {{ lst(Circuit.ECHO_FLOW) }} заряда. Уже один проход — победа, остальное — бонус.
  • {{ t('GATE CHAIN') }}: следующие ворота встают в {{ Circuit.CHAIN_AHEAD[0] }}–{{ Circuit.CHAIN_AHEAD[1] }} клетках прямо перед местом, где ты вышел из прошлых, на одной линии с выходом.

{{ t('RELAY') }}

{{ shots( img('relay', 'Реле: клемма 1 тронута, следующая — 2.'), img('relay_posts', 'После реле: тронутые клеммы стали живыми стойками.'), img('relay_bridge', t('BRIDGE RELAY') + ': стойки соединены шинами под током.'), ) }}

По полю расставляются пронумерованные клеммы, не ближе {{ Circuit.RELAY_SPREAD }} клеток друг к другу. Проведи по ним голову по порядку номеров, пока не вышло время.

  • Время: {{ steps(Circuit.RELAY_TIME) }} на три клеммы и ещё {{ Circuit.RELAY_TIME_PER_EXTRA }} шагов на каждую следующую.
  • Каждая клемма: +{{ Circuit.RELAY_NODE_PTS }} очков (× множитель) и +{{ Circuit.RELAY_NODE_FLOW }} заряда.
  • Завершение: +{{ Circuit.RELAY_DONE_PTS }} очков и минимум {{ Circuit.RELAY_DONE_FLOW }} заряда — всегда достаточно, чтобы дойти до следующего множителя (пока ты ниже ×{{ Circuit.RELAY_STAGE_CAP + 1 }}). Сложные варианты (четыре клеммы, быстрое, тёмное, живое) платят за завершение {{ x(Circuit.RELAY_BONUS_PCT / 100) }}.
  • Тронутая клемма становится живой стойкой, как только с неё ушло тело: врезаться нельзя, а для сближений годится. Стойки держатся {{ steps(Circuit.RELAY_POST_LIFE) }} после конца реле ({{ Circuit.RELAY_BRIDGE_LIFE }} с мостом).

{{ t('HOT ZONE') }}

{{ shots( img('hot', 'Появилась горячая зона — квадрат 5×5.'), img('hot_in', 'Голова в зоне: копилка растёт, это видно на полосе события.'), img('hot_cash', t('CASH') + ': выход из квадрата выплачивает накопленное.'), ) }}

Квадрат {{ Circuit.HOT_SIZE }}×{{ Circuit.HOT_SIZE }}. Пока голова внутри, заряд и очки копятся; выйди из квадрата, чтобы забрать их ({{ t('CASH') }}). Входить и выходить можно несколько раз. Если зона перегреется, когда голова ещё внутри, накопленное сгорает ({{ t('BURNED') }}).

  • Зона живёт {{ steps(Circuit.HOT_LIFE) }}; последние {{ Circuit.HOT_CRITICAL }} шагов — предупреждение.
  • Каждый шаг внутри копит {{ lst(Circuit.HOT_TICK) }} заряда (растёт по четвертям срока зоны) и {{ Circuit.HOT_TICK_PTS }} очка.
  • Всё, что ты зарабатываешь внутри, начисляется как обычно, и ещё {{ pct(Circuit.HOT_GAIN_PCT) }} от этого откладывается в копилку.
  • В зоне сближения заряжают полностью на любом множителе, и голод не действует.
  • Накопленные очки умножаются на множитель в момент выплаты. Событие засчитано, когда ты забрал в сумме не меньше {{ Circuit.HOT_SUCCESS }} заряда.

{{ t('LIVE WIRE') }}

{{ img('wire', 'Провод под током: первый из трёх проходов (' + t('SKIM %d/%d').replace('%d/%d', '1/3') + ').') }}

Смертельная шина длиной {{ Circuit.WIRE_LEN }} клетки ездит туда-сюда по своей полосе, на клетку каждые {{ Circuit.WIRE_PERIOD }} шага. Пройди впритирку к ней {{ Circuit.WIRE_SKIMS }} раза за {{ steps(Circuit.WIRE_TIME) }}. Касание — конец забега.

  • Проходы засчитываются не чаще чем раз в {{ Circuit.WIRE_SKIM_GAP }} шагов.
  • Каждый проход: +{{ Circuit.WIRE_SKIM_PTS }} очков (× множитель) и +{{ Circuit.WIRE_SKIM_FLOW }} заряда; победа над проводом: +{{ Circuit.WIRE_DONE_PTS }} очков и +{{ Circuit.WIRE_DONE_FLOW }} заряда.
  • Провод никогда не въезжает в голову или вплотную к ней и не встаёт на {{ Circuit.WIRE_AHEAD }} клетки прямо перед ней.
