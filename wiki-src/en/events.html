title: Circuit Events description: NEARCOIL Circuit Events — GATE, RELAY, HOT ZONE and LIVE WIRE: how each works, timers, payouts, every variant and modifier, and when they appear. lead: Every so often the board throws a short challenge at you: a Circuit Event. There are four kinds — {{ t('GATE') }}, {{ t('RELAY') }}, {{ t('HOT ZONE') }} and {{ t('LIVE WIRE') }} — and each has variants. Winning one pays points and charge and opens a module choice. ---

When events come

  • The first event starts after {{ steps(Circuit.FIRST_EVENT) }} of free play.
  • Between events there are {{ Circuit.GAP_MIN }}–{{ Circuit.GAP_MAX }} steps of free play. The pause shrinks by {{ Circuit.GAP_SHRINK }} steps with every event you complete, but never below {{ Circuit.GAP_FLOOR }}. If an event ended while you were at ×5 or more, you get {{ Circuit.RECOVERY_HOT }} extra calm steps.
  • An event never starts while you are inside a gap, and new structures appear at least {{ Circuit.SAFE_DIST }} cells from your head, never right in your path. If the board is too crowded the event waits a moment and tries again.
  • The live event's name, progress and timer are shown in the bar under the meter. The first time you meet each kind, a card explains it.
  • Running out of time just ends the event without a reward. Structures disappear when the event ends (relay posts stay a while longer).

Which event (Ranked and Daily)

The kinds come from a shuffled bag that never gives the same kind twice in a row. {{ t('LIVE WIRE') }} joins only after the first {{ Circuit.WIRE_AFTER }} events. Harder variants unlock with the run's intensity — the number of events completed so far, plus one while you are at ×5 or more. The tables below give the intensity each variant needs and its weight in the draw. Campaign levels list exactly which events and variants they use (see all levels).

Modifiers can be added on top (in Ranked and Daily by chance, as below; a Campaign level that lists a modifier puts it on every event it fits):

{{ t('GATE') }}

{{ shots( img('gate', 'A gate course: two rows of pylons with the door between them; the next gate is already waiting.'), img('gate_pass', 'A gate passed: the word shows its number in the course.'), img('gate_double', t('DOUBLE GATE') + ': two doors, either counts.'), img('gate_risk', t('RISK GATE') + ': the shallow door pays +25, the deep one +90.'), ) }}

A gate is a door — a straight passage 1–4 cells long — with a lethal pylon on each side of every door cell. To pass it, drive into the door and out the far side straight through, without turning inside. Either direction works. The door's length is its depth; deeper doors pay more.

  • Each gate must be passed within {{ steps(Circuit.GATE_TIME) }}; the timer restarts for the next gate of a course.
  • A new door appears {{ Circuit.GATE_REACH[0] }}–{{ Circuit.GATE_REACH[1] }} cells from your head. A pylon is never placed in your lane within {{ Circuit.GATE_LANE_CLEAR }} cells ahead, or in the lanes beside it within {{ Circuit.GATE_SIDE_CLEAR }} cells.
  • Pylons are conductors: brushing them is a close call (paid in full), driving between them counts as tight steps. A gap of pylons alone is not a maneuver — the gate pays for it.

Variants

{{ director_table('gate') }}
  • {{ t('RISK GATE') }}: shallow door (depth {{ Circuit.RISK_SAFE[0] }}) +{{ Circuit.RISK_SAFE[1] }} points and {{ Circuit.RISK_SAFE[2] }} charge; deep door (depth {{ Circuit.RISK_DEEP[0] }}) +{{ Circuit.RISK_DEEP[1] }} points and {{ Circuit.RISK_DEEP[2] }} charge. The first one you pass ends the event.
  • {{ t('ECHO GATE') }}: one door of depth {{ Circuit.ECHO_DEPTH }}, passed {{ Circuit.ECHO_PASSES }} times — there, back the other way, there again — each within {{ Circuit.ECHO_TIME }} steps. The passes pay {{ lst(Circuit.ECHO_PTS) }} points and {{ lst(Circuit.ECHO_FLOW) }} charge. One pass is already a win; the rest is bonus.
  • {{ t('GATE CHAIN') }}: each next gate appears {{ Circuit.CHAIN_AHEAD[0] }}–{{ Circuit.CHAIN_AHEAD[1] }} cells straight ahead of where you left the last one, lined up with your exit.

{{ t('RELAY') }}

{{ shots( img('relay', 'A relay: terminal 1 touched, number 2 is next.'), img('relay_posts', 'After the relay: the touched terminals are live posts.'), img('relay_bridge', t('BRIDGE RELAY') + ': the posts are joined by live bars.'), ) }}

Numbered terminals appear around the board, at least {{ Circuit.RELAY_SPREAD }} cells apart. Steer your head onto them in number order before time runs out.

  • Time: {{ steps(Circuit.RELAY_TIME) }} for three terminals, {{ Circuit.RELAY_TIME_PER_EXTRA }} steps more for each extra one.
  • Each terminal: +{{ Circuit.RELAY_NODE_PTS }} points (× multiplier) and +{{ Circuit.RELAY_NODE_FLOW }} charge.
  • Completion: +{{ Circuit.RELAY_DONE_PTS }} points and at least {{ Circuit.RELAY_DONE_FLOW }} charge — always enough to reach the next multiplier (as long as you are below ×{{ Circuit.RELAY_STAGE_CAP + 1 }}). The harder variants (four, fast, dark, live) pay ×{{ Circuit.RELAY_BONUS_PCT / 100 }} on completion.
  • A touched terminal becomes a live post once your body has left it: lethal, but good for close calls. Posts stay {{ steps(Circuit.RELAY_POST_LIFE) }} after the relay ends ({{ Circuit.RELAY_BRIDGE_LIFE }} with a bridge).

{{ t('HOT ZONE') }}

{{ shots( img('hot', 'A hot zone appears: a 5×5 square.'), img('hot_in', 'Inside the zone: the bank grows, shown on the event bar.'), img('hot_cash', t('CASH') + ': leaving the square pays the bank out.'), ) }}

A {{ Circuit.HOT_SIZE }}×{{ Circuit.HOT_SIZE }} square. While your head is inside it, charge and points bank up; leave the square to cash in ({{ t('CASH') }}). You can go in and out several times. If the zone overloads while your head is still inside, the bank burns ({{ t('BURNED') }}).

  • The zone lives {{ steps(Circuit.HOT_LIFE) }}; the last {{ Circuit.HOT_CRITICAL }} steps are a warning.
  • Every step inside banks {{ lst(Circuit.HOT_TICK) }} charge (rising by quarter of the zone's life) and {{ Circuit.HOT_TICK_PTS }} points.
  • Everything you earn inside is paid as usual and {{ pct(Circuit.HOT_GAIN_PCT) }} of it is banked on top.
  • Inside the zone close calls charge in full at any multiplier, and hunger does not apply.
  • Banked points are multiplied by your multiplier when you cash. The event counts as won once you have cashed at least {{ Circuit.HOT_SUCCESS }} charge.

{{ t('LIVE WIRE') }}

{{ img('wire', 'A live wire: the first of three skims (' + t('SKIM %d/%d').replace('%d/%d', '1/3') + ').') }}

A lethal bar {{ Circuit.WIRE_LEN }} cells long slides back and forth along a lane, one cell every {{ Circuit.WIRE_PERIOD }} steps. Pass right next to it {{ Circuit.WIRE_SKIMS }} times within {{ steps(Circuit.WIRE_TIME) }}. Touching it ends the run.

  • Skims count at least {{ Circuit.WIRE_SKIM_GAP }} steps apart.
  • Each skim: +{{ Circuit.WIRE_SKIM_PTS }} points (× multiplier) and +{{ Circuit.WIRE_SKIM_FLOW }} charge; beating the wire: +{{ Circuit.WIRE_DONE_PTS }} points and +{{ Circuit.WIRE_DONE_FLOW }} charge.
  • The wire never moves into or next to your head, nor onto the {{ Circuit.WIRE_AHEAD }} cells straight ahead of it.
