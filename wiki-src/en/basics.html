The board

  • The grid is {{ GameSim.W }} cells wide and {{ GameSim.H }} tall ({{ derived.cells }} cells). The edges kill.
  • The snake starts {{ GameSim.START_LEN }} cells long in the lower middle, heading up.
  • One step moves the head exactly one cell. You can't reverse into your own neck: a 180° turn is ignored.
  • Moving into the cell your tail is leaving on this step is allowed.
  • A run ends when the head hits the edge, your own body, or any lethal structure (pylon, live post, wire, insulator). In the Campaign it also ends when the time runs out or you reach PERFECT.

Controls

{{ img('controls', 'The first-run choice. It can be changed later in Settings → Controls.') }}

Three schemes, picked on the first run and changeable in Settings:

{{ t('CTRL_SWIPE') }} (default)

Flick the way you want to go. It fires mid-gesture as soon as the finger has moved about {{ int(Main.FLICK_DP) }} dp, so a very short flick is enough, and an L-shaped gesture makes two turns without lifting the finger. Screen direction = travel direction, which helps when the snake is heading down or sideways.

{{ t('CTRL_TAP') }}

Tap the left or right half of the screen to turn left or right as the snake sees it (when it heads down, "left" is on the right of the screen). It fires on touch-down. Good for one-handed play.

{{ t('CTRL_DPAD') }}

Four arrow keys, either in a strip under the board or over the board; the buttons can be shown always or only while touched.

Input buffer: up to two turns are queued, so a quick double input makes a U-turn over two steps. Turns are applied on the next grid step.

Pause and resume

After {{ t('RESUME') }} in the pause menu, and after a one-time explanation card, the board counts down ({{ GameController.COUNT_BEATS }} beats of {{ GameController.COUNT_BEAT }} s) before it moves again. Arrows from the head show which way the snake will start; steering during the count changes that first direction (a reversal is still ignored, steering straight on again cancels the turn). The tap that closes a card never steers. The video of the run skips the pause and the count.

Keyboard (desktop builds): arrows / WASD to steer, P to pause.

Speed

The step time depends on how many nodes you have eaten (never on time alone, so a patient player is not rushed), and on the multiplier.

{{ speed_table() }}

On top of that, the multiplier makes the snake faster: +{{ GameSim.FLOW_SPEED_PCT[1] }}% at ×2 up to +{{ GameSim.FLOW_SPEED_PCT[-1] }}% at ×{{ len(GameSim.FLOW_LEVELS) }} (see the table), and the SURGE module adds another +{{ Circuit.SURGE_SPEED_PCT }}%. The step never gets shorter than {{ GameSim.MIN_INTERVAL }} ms.

step = base step × 100 / (100 + multiplier bonus % + SURGE bonus %), at least {{ GameSim.MIN_INTERVAL }} ms

The board runs at its own step rate whatever the screen refresh rate: 60, 90 or 120 Hz only make the motion smoother.

Nodes and growth

Each node is worth {{ GameSim.FOOD_POINTS }} × multiplier points and makes the body longer. Early nodes grow it more, so there is soon enough body to build lanes with:

{{ growth_table() }}

After the {{ len(GameSim.GROWTH) }}th node every node adds {{ GameSim.GROW_LATE }} cells.

Where nodes appear

  • Never on the body or a structure, never on an event target, and always reachable from the head.
  • Never closer than 4 cells (in steps) to the head.
  • Cells right next to your body and at middle distance (up to 11 cells) are more likely: nodes tend to pull you back along your own lanes.
  • The placement is seeded, so a replay or a Daily board always gets the same nodes for the same moves.

Going long without eating has a cost: see hunger.
